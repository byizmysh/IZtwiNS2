# Building IZtwiNS2

The [source tree](source/) contains the code for both release builds and their corresponding FFmpeg and text dependencies.

- [Switch 2 SDK requirements and NRO build](source/README.md#build)
- [Native IZ2S build and packaging](source/README.md#build)

Run the build commands from `source/`. The native build also requires the IZ2S SDK and its hosted runtime tools. The release binaries appear in [Releases](https://github.com/byizmysh/IZtwiNS2/releases).
